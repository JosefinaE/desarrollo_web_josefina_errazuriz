# Tarea 1 desarrollo web

## Detalles para la corrección

Manejo de display de errores se realiza mediante errors.js y un div con id="errors" en el cual se agregan los spans.

Todas las funciones de validación de input se encuentran en validators.js

Para miembros.html se pusieron datos de ejemplo, la implementación de la paginación y de los filtros se dejó incompleta 
ya que esta va a depender del servidor web que se use.

Para actividades.html se asume que no es necesario preguntar los datos del usuario, ya que se usarán los del que esté registrado.

Para estadisticas.html solo se dejó la plantilla, los graficos e imagenes se dejaron comentados ya que serán implementados cuando el servidor web los pueda servir.
